# 🔒 로컬 개인정보 문서 정리 챗봇

> 인터넷 연결 없이 로컬 PC에서 동작하는 LLM으로, 문서 속 개인정보 항목을 자동 정리해주는 챗봇입니다.

[![Python](https://img.shields.io/badge/Python-3.13-blue.svg)](https://www.python.org/)
[![Ollama](https://img.shields.io/badge/LLM-Ollama%20(EXAONE%203.5)-black.svg)](https://ollama.com/)
[![Gradio](https://img.shields.io/badge/UI-Gradio-orange.svg)](https://www.gradio.app/)

---

## 📌 프로젝트 소개

이력서, 신청서, 계약서 등 **개인정보가 담긴 문서**를 업로드하면,
로컬에서 실행되는 LLM이 이름 · 연락처 · 이메일 · 주소 등 개인정보 항목을
자동으로 찾아 정리해주는 서비스입니다.

문서 내용을 외부 클라우드 API로 전송하지 않고, **전 과정이 사용자의 PC 안에서만** 처리됩니다.

---

## 🤔 왜 로컬 환경인가?

이 서비스가 다루는 문서에는 이름, 연락처, 주소 등 **민감한 개인정보**가
원문 그대로 포함되어 있습니다. 이런 문서를 외부 클라우드 LLM API로 전송하는 것은
개인정보보호 관점에서 리스크가 크기 때문에, 인터넷 연결 없이
**Ollama 기반 로컬 LLM**만으로 전체 파이프라인을 구성했습니다.

## ✅ 정확도는 어떻게 확보했는가?

LLM이 개인정보를 잘못 추출하거나 지어내면 위험하므로, 두 단계로 정확도를 보장했습니다.

1. **원문 전체를 프롬프트에 그대로 삽입** → LLM이 문서 밖 지식으로 답하지 못하도록 제한
2. **원문 대조 검증** → LLM이 추출한 값이 실제 문서 원문에 존재하는 문자열인지 코드로 재검증하고,
   존재하지 않으면 `⚠ 확인 필요`로 표시하여 잘못된 정보가 그대로 노출되지 않도록 함

## 🛠️ 기술 스택

| 구분 | 기술 |
|---|---|
| LLM | Ollama (`exaone3.5:2.4b`) |
| 언어 | Python 3.13 |
| UI | Gradio |
| 문서 처리 | pypdf |

---

## 🚀 실행 방법

```bash
# 1) 모델 다운로드 (최초 1회)
ollama run exaone3.5:2.4b

# 2) 라이브러리 설치
pip install ollama gradio pypdf

# 3) 실행
python app.py
```

실행 후 터미널에 출력되는 주소로 접속하면 됩니다.

---

## 📂 사용 방법

1. PDF 또는 TXT 문서를 업로드
2. `정리하기` 버튼 클릭
3. 이름 / 연락처 / 이메일 / 주소 항목이 정리되어 출력
4. 원문에 없는 값은 `⚠ 확인 필요`로 별도 표시
