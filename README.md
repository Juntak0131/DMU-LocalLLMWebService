# 개인정보 문서 정리 챗봇 — 실습 1

## 실행 방법
```bash
# 1) 모델이 없다면 최초 1회만 받기
ollama run exaone3.5:2.4b

# 2) 라이브러리 설치
pip install ollama gradio pypdf

# 3) 실행
python app.py
```
실행 후 `http://127.0.0.1:7860` 접속.

## 핵심 아이디어
1. 문서(PDF/TXT) 원문 전체를 추출해 프롬프트에 통째로 삽입 → LLM이 문서 밖 지식으로 답하지 못하게 제한
2. LLM이 추출한 값이 원문에 실제로 존재하는 문자열인지 코드로 재대조 → 없으면 "확인 필요"로 표시
3. → 이 2단계 구조가 "정확도 문제없는 개발" 요건의 핵심 근거

## 팀 역할 분담
- **PM**: `app.py` 하단 주석에 발표 포인트 정리됨 → 그대로 발표
- **백엔드**: `extract_text`, `extract_personal_info`, `verify_against_source` 함수
- **프론트**: `gr.Blocks()` UI 부분 (문구/레이아웃 자유 수정 가능)
- **기타**: 실제 개인정보가 담긴 샘플 문서(가짜 데이터)로 테스트, GitHub 업로드

## 시연 팁
- 이름/연락처가 명확히 적힌 짧은 샘플 문서(txt)로 먼저 테스트 → 정상 추출 확인
- 일부러 문서에 없는 항목을 물어봐서 "없음"으로 잘 나오는지 확인 (정확도 근거로 발표 시 활용)
